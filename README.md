# 🤖 n8n AI Automation Workflows

A collection of AI-powered automation workflows built with **n8n**. This repository includes real-world projects such as AI agents, RAG chatbots, Telegram bots, client onboarding systems, and business automation workflows.

## 🚀 Technologies

- n8n
- AI Agents
- Groq
- Pinecone
- OpenAI Embeddings
- Telegram Bot API
- Google Drive
- RAG (Retrieval-Augmented Generation)

## 📂 Projects

- 🤖 Telegram AI Assistant
- 📚 RAG Portfolio Chatbot
- 👋 Client Onboarding System
- 🔄 Workflow Automation
- 🚀 More projects coming soon...

## ⚙️ Getting Started

1. Import the desired workflow into n8n.
2. Configure your own credentials.
3. Update the required settings.
4. Execute the workflow.
